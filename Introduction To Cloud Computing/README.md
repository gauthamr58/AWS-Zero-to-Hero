## Introduction to Cloud Computing



Cloud computing is a modern approach to delivering IT resources over the internet. Instead of owning and maintaining physical infrastructure, organizations can access computing services on demand, paying only for what they use.

---

## 1. What is an On-premise Setup?

An **on-premise** setup refers to traditional IT Infrastructure where all hardware, software, and networking components are **installed and managed within an organization's own physical location** (such as a data centre).

### Key characteristics:

* Serveres are hosted inside the organization
* Hardware procurement and maintenance are organization's responsibility
* Requires dedicated IT staff
* High upfront capital investement
* Limited scalability

**Example:**
A company buying physical serverrs, installing them in a server room, and managing power, cooling, backups on its on.

---

## 2. What is Cloud?

The **cloud** refers to a network of remote severs hosted on the internet that are used to store manage, and process data instead of local servers or personal computers

These servers are owned and maintained by **cloud service providers** such as:

* Amazon Web services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

---

## 3. What is Cloud Computing?

**cloud computing** is the on-demand delivery of computing services such as servers, storage, database, networking, software, and analytics over the internet on a **pay-as-you-go** basis

### Core concept:
>"Access IT Resources on demand without owning the infrastructure"
